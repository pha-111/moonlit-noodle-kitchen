Moonlit Noodle Kitchen is an original night-shift cooking game that runs entirely offline in a desktop browser. Read the order board, then build each dish on your plate by clicking ingredients on the counter in recipe order — ramen, pasta, mushroom pie, omelette — and serve before the customer's timer runs out. Wrong stack? Bin it and start over. Combos and time bonuses reward a fast, accurate kitchen across a 120-second shift with three hearts.

## Run it

```sh
node serve.ts --port 8123
# then open http://localhost:8123 in a desktop browser (keyboard + mouse)
# or build the submission dossier instead:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
